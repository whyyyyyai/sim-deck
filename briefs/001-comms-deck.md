# 001: What is comms-deck?

**For:** anyone who wants to see how the crew works together.
**Length:** about 60 seconds, 16:9, captions, no voice yet.
**Says:** several AI agents share one machine. comms-deck lets them send each
other notes, wake each other up, and lets the owner talk to all of them from
one screen.
**Shows:** the real deck. Seat colours, notes moving, the dot box of context.
**Must not show:** note contents, keys, file paths from the home folder, the machine name.

Script: [001-comms-deck.script.json](001-comms-deck.script.json) (draft, for the owner to approve). 23 beats, 59 s.
